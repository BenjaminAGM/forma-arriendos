# Forma · Arriendos para eventos

Demo interactiva de Benjamín Gómez. Un catálogo de mobiliario que permite elegir piezas, calcular cantidades y preparar una solicitud de cotización para WhatsApp.

[Abrir la demo](https://forma-eventos-benjamin-gomez.chatngiept.chatgpt.site/?v=3)

## Probar en 30 segundos

1. Abre la demo y entra a Montajes.
2. Elige un montaje para 12 o 30 personas y ajusta las cantidades.
3. Completa fecha y comuna para ver el mensaje de cotización.

## Funcionalidades

- Seis productos con filtros por categoría y cantidades editables.
- Montajes predefinidos con planos y subtotales en pesos chilenos.
- Vista previa del mensaje, copia al portapapeles y apertura de WhatsApp.
- Diseño adaptable y animaciones que respetan la preferencia de movimiento reducido.

## Ejecutar

Abre `index.html` en un navegador. Para servir la carpeta localmente, con Python instalado:

```sh
python -m http.server 8000
```

Visita http://localhost:8000.

## Publicar en GitHub Pages

En Settings → Pages, elige Deploy from a branch, la rama main y la carpeta / (root).
